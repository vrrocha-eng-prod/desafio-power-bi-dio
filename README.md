# 📊 Desafio Power BI - Formação Power BI Analyst DIO

Projeto prático desenvolvido para treinar a criação e disposição de visuais no Microsoft Power BI com a base de dados *Financial Sample*.

## 📌 Conteúdo Desenvolvido
- **Mapa 1:** Volume de vendas e total de unidades comercializadas por país.
- **Mapa 2:** Lucro total acumulado por país.
- **Gráfico de Pizza:** Distribuição do lucro líquido por segmento de cliente.
- **Dicas de Ferramentas (Tooltips):** Informações contextuais adicionadas aos visuais.
